# Portfólio — Vito Andrade

Portfólio pessoal de **Vito Andrade**, estudante de Engenharia de Software interessado em desenvolvimento web e design UX/UI. O site apresenta meu perfil, trajetória, projetos e formas de contato.

## ✨ Sobre o projeto

O portfólio reúne:

- Apresentação e resumo profissional;
- Seções de educação, experiência e projetos;
- Links para redes sociais e contato;
- Acesso para baixar o currículo;
- Interface responsiva com animações e menu interativo.

## 🛠️ Tecnologias

- HTML5 e CSS3
- JavaScript
- React 19
- Vite
- Motion

## 🚀 Como executar localmente

Você precisa ter o [Node.js](https://nodejs.org/) instalado.

1. Clone o repositório:

   ```bash
   git clone https://github.com/VitorAndrade5/Portifolio.git
   cd Portifolio
   ```

2. Instale as dependências:

   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```

4. Abra no navegador o endereço exibido pelo Vite no terminal.

## 📦 Outros comandos

```bash
npm run build    # Gera a versão de produção em dist/
npm run preview  # Pré-visualiza a versão de produção
```
